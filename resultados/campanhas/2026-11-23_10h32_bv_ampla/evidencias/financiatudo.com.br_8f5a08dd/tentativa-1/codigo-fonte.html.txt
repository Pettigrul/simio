            </p>

            <details class="faq-item">
              <summary>
                <span class="faq-pergunta">
                  O que é financiamento de veículos?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                É uma modalidade de crédito utilizada para adquirir um veículo, na qual uma instituição financeira paga o valor da compra ao vendedor e o cliente realiza o pagamento por meio de parcelas, conforme as condições aprovadas.
              </div>
            </details>

            <details class="faq-item">
              <summary>
                <span class="faq-pergunta">
                  Como funciona o financiamento de veículos?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                O cliente escolhe o veículo e solicita uma proposta de financiamento. A instituição financeira analisa o perfil, o veículo e as condições da operação. Se aprovado, o financiamento é formalizado e o pagamento ao vendedor é realizado conforme as regras da instituição.
              </div>
            </details>

            <details class="faq-item">
              <summary>
                <span class="faq-pergunta">
                  Quais veículos podem ser financiados?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Podem ser financiados diferentes tipos de veículos, como carros, utilitários e outros veículos elegíveis pelas instituições financeiras parceiras, desde que atendam aos critérios de aceitação e análise.
              </div>
            </details>

            <details class="faq-item">
              <summary>
                <span class="faq-pergunta">
                  É possível financiar veículos novos e usados?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Sim. É possível encontrar opções para veículos novos e usados, dependendo das regras da instituição financeira, do veículo e do perfil do cliente.
              </div>
            </details>

            <details class="faq-item">
              <summary>
                <span class="faq-pergunta">
                  Preciso dar entrada para financiar um veículo?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                A necessidade e o percentual de entrada dependem da análise da instituição financeira, do valor do veículo, de suas características e do perfil do cliente. Em algumas operações, pode haver possibilidade de financiar uma parcela maior do valor.
              </div>
            </details>

            <details class="faq-item">
              <summary>
                <span class="faq-pergunta">
                  Qual valor do veículo pode ser financiado?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                O valor financiado depende do preço do veículo, da entrada, da análise de crédito e das condições aprovadas pela instituição financeira.
              </div>
            </details>

            <details class="faq-item">
              <summary>
                <span class="faq-pergunta">
                  Posso financiar 100% do valor do veículo?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                A possibilidade de financiar todo o valor depende das políticas da instituição financeira e da análise da operação. A aprovação pode exigir entrada, conforme o perfil do cliente e as características do veículo.
              </div>
            </details>

            <details class="faq-item">
              <summary>
                <span class="faq-pergunta">
                  Como são definidas as parcelas do financiamento?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                As parcelas são determinadas principalmente pelo valor financiado, taxa de juros, prazo escolhido e demais condições da operação aprovadas pela instituição financeira.
              </div>
            </details>

            <details class="faq-item">
              <summary>
                <span class="faq-pergunta">
                  Qual é o prazo para pagar o financiamento?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                O prazo varia conforme a instituição financeira, o tipo, o ano e as características do veículo, além do perfil do cliente e das condições aprovadas.
              </div>
            </details>

            <details class="faq-item">
              <summary>
                <span class="faq-pergunta">
                  Como funciona a aprovação do financiamento de veículos?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                A instituição financeira realiza uma análise de crédito considerando informações do cliente, sua capacidade de pagamento, histórico financeiro e as características da operação e do veículo.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  É possível financiar um veículo sem entrada?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Em determinadas situações, pode existir financiamento com pouca ou nenhuma entrada, mas isso depende das condições oferecidas pela instituição financeira e da análise de crédito do cliente.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Posso escolher o veículo antes de solicitar o financiamento?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Sim. O cliente pode escolher o veículo e, a partir das informações do veículo, solicitar uma proposta para verificar as condições disponíveis.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Posso financiar um veículo comprado de particular?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                A possibilidade depende das regras da instituição financeira. Algumas operações podem aceitar veículos adquiridos de particulares, desde que sejam cumpridos os procedimentos e critérios exigidos.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  É possível financiar veículo comprado em loja ou concessionária?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Sim. O financiamento pode ser utilizado para aquisição de veículos em lojas e concessionárias que atendam aos procedimentos exigidos pela instituição financeira.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Quais documentos são necessários para financiar um veículo?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Normalmente são solicitados documentos pessoais, comprovantes de renda e endereço, além das informações e documentos relacionados ao veículo. A relação pode variar conforme a instituição financeira e o perfil do cliente.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Preciso comprovar renda para conseguir o financiamento?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                A instituição financeira pode solicitar comprovação de renda para avaliar a capacidade de pagamento do cliente. Os documentos aceitos dependem das regras da instituição.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Quem pode solicitar um financiamento de veículos?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Pessoas que atendam aos critérios de crédito e documentação da instituição financeira podem solicitar o financiamento. A aprovação depende da análise individual de cada proposta.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Quem está negativado pode financiar um veículo?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                A aprovação para clientes com restrições no CPF depende das políticas de cada instituição financeira e da análise realizada. A existência de restrição pode dificultar a aprovação, mas cada proposta deve ser avaliada individualmente.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Posso financiar um veículo mesmo tendo outros empréstimos?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Ter outros compromissos financeiros não impede necessariamente uma nova operação. A instituição financeira avaliará a capacidade de pagamento e o comprometimento de renda antes de decidir sobre a aprovação.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  É possível financiar um veículo para trabalhar?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Sim. O veículo financiado pode ser utilizado para atividades profissionais, desde que a operação e o veículo estejam de acordo com as condições da instituição financeira.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Posso financiar um veículo para uso pessoal?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Sim. O financiamento pode ser utilizado para aquisição de veículo destinado ao uso pessoal, observadas as condições da instituição financeira.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  O ano do veículo influencia na aprovação?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Sim. O ano de fabricação/modelo pode influenciar a aceitação do veículo, o prazo disponível e as condições do financiamento. Cada instituição possui seus próprios critérios.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Veículos mais antigos podem ser financiados?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Algumas instituições aceitam veículos usados e mais antigos, enquanto outras estabelecem limites de idade. A possibilidade depende das regras vigentes para cada operação.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  A instituição financeira avalia o veículo antes de liberar o financiamento?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Podem ser realizadas verificações relacionadas ao veículo, incluindo informações cadastrais, documentação, valor e condições exigidas pela instituição financeira.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  O veículo fica em garantia no financiamento?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Sim. No financiamento de veículos, normalmente é constituída uma garantia sobre o próprio veículo até a quitação da operação, conforme o contrato firmado com a instituição financeira.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Posso vender o veículo enquanto ele está financiado?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                A venda de um veículo financiado depende da situação do contrato e das regras da instituição financeira. É necessário verificar o saldo devedor e os procedimentos para transferência ou quitação da operação.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Posso antecipar parcelas do financiamento?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                A possibilidade de antecipação ou quitação antecipada existe conforme as condições do contrato e as regras aplicáveis à operação. O cliente pode solicitar à instituição financeira o cálculo para antecipação ou quitação.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Posso quitar o financiamento antes do prazo?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Sim. O cliente pode solicitar a quitação antecipada, observadas as condições contratuais e os procedimentos da instituição financeira responsável pelo financiamento.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  As taxas de juros são iguais para todos os clientes?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Não necessariamente. As condições podem variar de acordo com a instituição financeira, perfil de crédito, valor financiado, prazo, veículo, entrada e demais características da operação.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  A Financia Tudo aprova o financiamento de veículos?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Não. A Financia Tudo atua como intermediadora na busca de soluções financeiras. A análise, aprovação, definição das condições e liberação do crédito são realizadas pela instituição financeira responsável pela operação.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Como faço uma simulação de financiamento de veículos?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Você pode solicitar uma simulação informando seus dados e as características do veículo que deseja financiar. A partir dessas informações, será possível avaliar as opções disponíveis para o seu perfil e para a operação.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Quais fatores podem melhorar as condições do financiamento?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Uma boa capacidade de pagamento, documentação adequada, entrada maior, escolha de um veículo dentro dos critérios da instituição e um bom histórico de crédito podem contribuir para condições mais favoráveis, embora não garantam aprovação ou determinada taxa.
              </div>
            </details>

            <details class="faq-item" data-faq-extra="" hidden="">
              <summary>
                <span class="faq-pergunta">
                  Posso comparar propostas de diferentes instituições financeiras?
                </span>
                <span class="faq-icone"></span>
              </summary>
              <div class="faq-resposta">
                Sim. A comparação entre propostas pode ajudar a identificar diferenças de taxas, prazo, entrada, valor financiado e parcelas. A disponibilidade das condições depende das instituições financeiras participantes da operação.
              </div>
            </details>

    const list = document.querySelector('#faq-lista');
    if (!list) return;

    const section = list.closest('.faq');
    const input = section.querySelector('#faq-busca');
    const status = section.querySelector('#faq-busca-status');
    const items = Array.from(section.querySelectorAll('.faq-item'));
    const categories = Array.from(section.querySelectorAll('[data-faq-categoria]'));
    const initialCategoryVisibility = new Map(
      categories.map((category) => [category, !category.hidden])
    );
    const footer = section.querySelector('.faq-footer');
    const toggle = section.querySelector('#faq-ver-todas');
    let expanded = false;

    const normalizeText = (text) => text
      .normalize('NFD')
      .replace(/[&#768;-&#879;]/g, '')
      .toLowerCase();

    const updateFaq = () => {
      const query = normalizeText(input.value.trim());
      let matches = 0;

      items.forEach((item, index) => {
        const question = item.querySelector('.faq-pergunta');
        const matchesQuery = !query || normalizeText(question.textContent).includes(query);
        const visibleInList = expanded || index < 10 || Boolean(query);

        item.hidden = !(matchesQuery && visibleInList);

        if (query && matchesQuery) {
          matches += 1;
        }
      });

      categories.forEach((category) => {
        category.hidden = Boolean(query)
          || (!expanded && !initialCategoryVisibility.get(category));
      });

      footer.hidden = Boolean(query);

      if (query) {
        status.hidden = false;
        status.textContent = matches === 0
          ? 'Nenhuma pergunta encontrada.'
          : matches === 1
            ? '1 pergunta encontrada.'
            : `${matches} perguntas encontradas.`;
      } else {
        status.hidden = true;
        status.textContent = '';
      }

      toggle.setAttribute('aria-expanded', String(expanded));
      toggle.textContent = expanded
        ? 'Mostrar menos &uarr;'
        : 'Ver todas as perguntas &rarr;';
    };

    input.addEventListener('input', updateFaq);
    toggle.addEventListener('click', function (event) {
      event.preventDefault();
      expanded = !expanded;
      updateFaq();
    });

    updateFaq();
